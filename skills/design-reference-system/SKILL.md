# Design Reference System

## Purpose
Use references to sharpen decisions, not to copy interfaces.

The goal is to extract principles from strong examples and synthesize them into a distinct visual system suited to the current brand, audience, content and conversion objective.

## Reference routing

Use only the smallest relevant subset.

### Overall art direction / hero composition
- jiro.build
- unsection.com
- ditther.com

Use for:
- editorial composition
- unusual section rhythm
- expressive hero layouts
- visual storytelling
- controlled asymmetry

### Navigation
- navbar.gallery

Study:
- hierarchy
- active states
- compactness
- mobile transformation
- transparency/solid transitions
- CTA placement

### Footers
- footer.design

Study:
- information hierarchy
- high-value final CTA
- brand closure
- legal/navigation density
- responsive stacking

### Calls to action
- cta.gallery

Study:
- CTA framing
- surrounding proof
- urgency without manipulation
- placement
- visual emphasis

### 404 / empty / edge states
- 404s.design
- ascii-magic.com

Use for:
- personality
- branded error states
- lightweight visual delight
- memorable empty states

### Bento and modular composition
- bentogrids.com
- unsection.com

Use only when content genuinely benefits from modular grouping.
Do not force bento grids into every homepage.

### Microinteractions and product UI
- 60fps.design
- interfaces.dev
- spottedinprod.com

Study:
- state changes
- loading
- hover/focus feedback
- drawers
- transitions
- progressive disclosure
- compact interaction patterns

### Mockups and presentation
- ultramock.io
- animos.app

Use for:
- product framing
- device presentation
- launch visuals
- portfolio showcases

### Background systems
- backgrounds.supply
- ditther.com
- ascii-magic.com

Use for:
- subtle texture
- depth
- atmosphere
- non-flat canvases

### Texture / material inspiration
- doronsupply.com

Use sparingly to add tactile character without reducing readability.

## Reference workflow

1. Identify the design problem first.
2. Select 2 to 5 relevant sources maximum.
3. Extract principles, not screenshots to copy.
4. Write a short direction:
   - composition
   - typography
   - spacing
   - color
   - image treatment
   - interaction
5. Adapt the direction to the brand and content.
6. Check that the result still works without decorative effects.

## Anti-copy rule
Never reproduce a reference site's:
- full layout
- distinctive proprietary illustration
- branded copy
- exact component arrangement
- trademarked visual identity

Use references as evidence of patterns, not templates.

## Anti-slop gate
Reject a direction if it relies mainly on:
- generic gradients
- glass cards
- floating blobs
- random 3D objects
- fake dashboards
- feature-card grids with no hierarchy
- motion that does not support comprehension

A strong site should have one coherent visual idea that belongs to the brand.
