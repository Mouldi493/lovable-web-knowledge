# SaaS Conversion

## Primary objective
Move the right visitor from understanding to first value with minimal friction.

## Homepage message
The first screen should answer:
- what the product does
- who it is for
- why it matters
- what to do next

Avoid category jargon unless the audience already uses it.

## Product proof
Software should show the software.

Prefer:
- screenshots
- short demos
- annotated flows
- interactive examples
- before/after workflow comparison
- concrete outputs

Do not rely entirely on abstract illustrations.

## Page structure
Common useful sequence:
promise → product proof → use cases → mechanism/features → proof → pricing/CTA → objections.

Adapt to awareness and complexity.

## Feature communication
For each major feature, connect:
feature → workflow change → outcome.

Do not create a wall of feature cards with no prioritization.

## Use cases
Use cases should map to actual jobs and buyer segments.

Good use-case content answers:
- who
- starting problem
- how the product helps
- resulting workflow/outcome
- relevant feature proof

## Signup
Reduce friction:
- ask only required information
- avoid premature profile fields
- preserve context after auth
- make errors actionable
- explain why sensitive information is needed
- support common auth methods when appropriate

## Activation
Define the first meaningful value event.

Design onboarding to reach it quickly.

Prefer:
- guided setup
- useful defaults
- progressive disclosure
- contextual education

Avoid long product tours before action.

## Empty states
Every empty state should help the user take the next meaningful action.

## Pricing
Make clear:
- who each plan is for
- included limits
- value metric
- monthly/annual relationship
- trial/free-plan constraints
- upgrade trigger

Do not hide important plan limitations.

## Paywalls and upgrades
Ask for upgrade after the user understands value.

Good upgrade prompts explain:
- what limit was reached
- what upgrading unlocks
- why it matters now

Avoid aggressive blocking before value.

## Social proof
Use:
- customer logos when authorized
- verified metrics
- case studies
- quotes
- usage volume only when real

Match proof to the buyer segment when possible.

## Metrics
Important SaaS funnel metrics may include:
- landing → signup
- signup completion
- activation
- time to value
- trial → paid
- expansion
- churn

Do not optimize signup rate if low-quality signups damage activation and revenue.
