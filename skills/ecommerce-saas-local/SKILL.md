# Ecommerce, SaaS and Local Business Patterns

## Ecommerce

### Product page
Above the fold should communicate:
- what the product is
- core benefit
- price
- variant/pack selection
- CTA
- delivery/returns reassurance
- essential proof

Then support the decision with:
- benefits
- demonstration
- specifications translated into meaningful outcomes
- proof
- objections/FAQ
- complementary products when genuinely useful

### Cart
- Keep item details clear.
- Make quantity editing easy.
- Surface shipping thresholds honestly.
- Avoid surprise fees.
- Use upsells sparingly and contextually.
- Never add items without explicit user action.

### Trust
Use real reviews and policies.
Never fake urgency, low stock, ratings or social proof.

## SaaS

### Marketing page
Communicate:
- category/problem
- promise
- product mechanism
- screenshots/demo
- use cases
- proof
- pricing/CTA

### Signup
- Remove unnecessary fields.
- Explain value before asking for commitment.
- Make authentication errors clear.
- Preserve user progress when possible.

### Onboarding
Drive toward the first meaningful result.
Avoid tours that explain every feature before value is experienced.

### Pricing
- Make plan differences explicit.
- Highlight the value metric.
- Explain limits.
- Avoid manipulative dark patterns.

## Local services

### Homepage/service pages
Prioritize:
- service clarity
- area served
- credibility
- process
- proof
- response/contact path

### Local conversion
Useful CTAs include:
- request a quote
- call
- book
- send a message

Choose one primary action.

### Trust
Use real:
- reviews
- before/after work
- certifications
- experience
- service area
- process
- guarantees where legitimate

### Local SEO
Create location pages only when there is enough unique, useful content for that location.
