# Premium Web Design

## Goal
Create a coherent visual system with perceived quality, not a collage of fashionable effects.

## Art direction
Before designing many sections, choose:
- visual premise
- emotional tone
- typography direction
- color system
- image style
- spacing rhythm
- component language
- motion language

Commit to one direction unless evidence requires a change.

## Anti-generic rules
Avoid default AI-site clichés:
- random purple/blue gradients
- glass cards everywhere
- excessive neon glow
- meaningless blobs
- identical 3-column feature cards for every topic
- arbitrary bento grids
- giant rounded rectangles everywhere
- excessive pill labels
- animation with no UX purpose
- decorative dashboards that show fake data

## Design system
Define tokens for:
- canvas/background
- surface
- primary text
- secondary text
- accent
- borders
- success/warning/error
- spacing
- radius
- shadow
- content widths
- breakpoints

Define reusable:
- buttons
- links
- inputs
- cards
- badges
- navigation
- modal/drawer
- alerts
- pricing cards
- product cards when relevant

## Typography
- Use a deliberate scale.
- Keep readable body sizes and line heights.
- Use display typography to create character, not to sacrifice legibility.
- Limit the number of typefaces and weights.
- Avoid using font size alone for hierarchy.

## Layout
- Use consistent containers and rhythm.
- Build strong alignment.
- Let important content breathe.
- Use asymmetry intentionally, not accidentally.
- Do not overload above-the-fold areas.

## Imagery
- Prefer genuine product, team or environment assets when available.
- Generated imagery must support the product story and should not misrepresent reality.
- Keep image grading and crop logic consistent.
- Avoid low-value decorative stock imagery.

## Responsive
Design desktop and mobile intentionally.
Check:
- navigation collapse
- content order
- image crops
- CTA reachability
- card stacking
- spacing
- readable line lengths
- sticky elements
- overflow

## Motion
Use motion for:
- state changes
- focus
- feedback
- hierarchy
- reveal
- spatial continuity

Keep it subtle, performant and compatible with reduced motion.

## Premium quality gate
Before completion, ask:
- Does this look like one brand?
- Is hierarchy obvious in 3 seconds?
- Is anything decorative competing with the CTA?
- Is there a signature visual idea?
- Does mobile feel designed, not compressed?
- Are interactions consistent?
- Does the design still work with animations disabled?
