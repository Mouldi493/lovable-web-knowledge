# Advanced Ecommerce CRO

## Primary objective
Reduce uncertainty and make the buying decision easier without manipulative patterns.

## Product-page hierarchy

### Above the fold
Show, in a scannable order:
- what the product is
- primary benefit
- price and any truthful savings
- ratings/reviews only if real
- variant, size, color or pack choices
- stock/delivery information when verified
- primary add-to-cart action
- returns or guarantee reassurance when real

Important purchase information should not be buried below brand storytelling.

## Product imagery
The gallery should answer buying questions.

Prioritize:
1. clear product hero
2. product in use
3. scale/context
4. important detail
5. inside/material/texture
6. before/after when truthful
7. packaging or included items
8. short demonstration video when useful

Keep crops, backgrounds, typography and branding consistent.

## Benefits
Translate specifications into consequences.

Bad:
"39 × 19 cm, thick fibers."

Better:
"Room for the full shoe while the soft interior helps limit rubbing during the wash."

Do not invent benefits that are not supported by the product.

## Variant and pack selection
For multi-pack offers:
- make quantity choices visually obvious
- show total price
- show price per unit when useful
- show truthful savings
- clearly mark the recommended/best-value option
- update the CTA/state correctly

Avoid confusing dropdowns when 2–4 commercial options can be compared directly.

## Offer design
Useful ecommerce offer levers:
- bundles
- quantity breaks
- free-shipping thresholds
- replenishment/subscriptions
- complementary products
- gifts when economically sensible

Do not use fake discounts or permanently inflated compare-at prices.

## Proof
Use real:
- Judge.me/verified reviews
- UGC
- customer photos
- demonstrations
- return rate or satisfaction metrics only when verified
- press/creator proof only when legitimate

Place proof next to the objection it resolves.

## Objection handling
Typical ecommerce objections:
- Does it work?
- Will it fit?
- Is it safe for my product/material?
- How do I use it?
- How long does delivery take?
- Can I return it?
- What exactly is included?
- Is the higher pack worth it?

Answer with concise visible content before relying on a long FAQ.

## Cart
Optimize:
- clear product/variant names
- editable quantity
- transparent subtotal
- delivery threshold progress only if truthful
- one or two relevant upsells maximum
- clear checkout CTA

Never silently add products.

## Sticky add-to-cart
On mobile, use when the primary CTA would otherwise disappear during a long product page.

It must:
- reflect selected variant
- show correct price
- not cover important UI
- remain accessible
- disappear/behave correctly around cart overlays

## Collection pages
Help users choose:
- meaningful category names
- useful filters
- clear product cards
- price visibility
- relevant badges only
- consistent image ratios

## Checkout-adjacent trust
Before checkout, clarify:
- shipping
- returns
- secure payment
- support/contact
- estimated delivery where available

## CRO priority order
Fix in this order:
1. broken buying flow
2. unclear offer/product
3. trust gaps
4. mobile friction
5. weak media
6. weak benefit communication
7. merchandising
8. microcopy/polish

Do not A/B test obvious defects.
