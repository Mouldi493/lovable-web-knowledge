# SEO and Discoverability

## Principle
Create useful, crawlable, understandable pages for real intent. Do not manufacture thin pages for keywords.

## Page fundamentals
Each important page should have:
- one primary intent
- descriptive title
- useful meta description
- one clear H1
- logical headings
- readable copy
- descriptive internal links
- canonical URL when needed
- appropriate indexability

## Technical basics
Check:
- robots directives
- sitemap behavior
- canonical tags
- redirects
- broken links
- duplicate content
- status codes
- Core Web Vitals
- mobile rendering
- structured data validity

## Local SEO
For local businesses:
- make real service areas clear
- use consistent business information
- create useful location content only when genuinely distinct
- include local proof when real
- connect services to geographic intent naturally

Avoid doorway pages that only swap city names.

## Internal linking
Use links to reinforce:
- hierarchy
- topic relationships
- high-value conversion pages
- supporting content

Anchor text should be descriptive.

## Structured data
Use schema only when it reflects visible truthful content.
Common types:
- Organization / LocalBusiness
- Product
- BreadcrumbList
- Article
- FAQPage when actual FAQs are visible and appropriate

Never mark up fabricated reviews or hidden content.

## Content strategy
Prioritize topics by:
- audience need
- business relevance
- realistic authority
- conversion potential
- search demand/intent

Prefer a strong cluster of useful content over high volume.

## AI/LLM discoverability
Make key facts explicit and consistent:
- what the company/product is
- who it serves
- core features/services
- pricing when public
- geography
- proof
- comparisons
- FAQs
- documentation

Use clear entity names, headings, concise factual statements and structured data where accurate.

Do not create content solely to manipulate AI citations.
